# ПОСИДИМ

Первая демо-версия приложения для поиска компании и организации встреч. Проект рассчитан на Android, iOS и Web на базе Expo + React Native + TypeScript.

## Что уже есть

- Тёмный интерфейс ПОСИДИМ
- Лента демонстрационных встреч
- Поиск по названию и месту
- Фильтры по категориям
- Демонстрационная запись на встречу (состояние хранится только пока открыто приложение)
- Адаптивная ширина для веб-версии
- Напоминание о безопасности и аудитории 18+

## Запуск на компьютере

Нужен Node.js LTS. В терминале VS Code выполни:

```bash
npm install
npx expo start
```

Для запуска в браузере:

```bash
npx expo start --web
```

Открой адрес, который покажет Expo. Для телефона можно установить Expo Go и отсканировать QR-код.

## Важно

Это ранний интерфейсный прототип. Встречи пока демонстрационные; регистрация, профили, геолокация, реальные заявки, чат, серверная база данных и модерация ещё не подключены. Не используй демо-данные как реальные встречи.
