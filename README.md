# ПОСИДИМ

ПОСИДИМ — приложение 18+ для знакомств, поиска компании поблизости и организации совместных встреч: кофе, прогулки, игры, спорт и общение.

Платформы: Web, Android и iOS. Стек: Expo SDK 54, React Native, TypeScript, Supabase.

## Возможности

- Регистрация и вход по email, восстановление забытого пароля по ссылке из письма, профиль 18+ и редактирование данных.
- Аватар, фотогалерея, описание и временный статус.
- Индикатор заполнения профиля и быстрый выбор занятия для спонтанной встречи; последнее занятие и время сохраняются локально на устройстве.
- Поиск профилей, симпатии и взаимные совпадения.
- Настройки, кто может начинать личный чат.
- Личные сообщения и групповые чаты встреч с обновлением сообщений в реальном времени.
- Список личных чатов с последним сообщением, временем, сортировкой по активности и поиском по имени/тексту.
- История личных и групповых чатов загружается страницами; черновики сообщений сохраняются на устройстве.
- Поиск доступен в списке чатов и внутри загруженной истории личных и групповых переписок.
- Удержанием чужого сообщения можно отправить жалобу с его текстом и указанием автора.
- После взаимной симпатии можно сразу перейти к личному чату из экрана совпадений.
- Подсказки для начала разговора.
- Создание встреч с выбором будущей даты и времени, редактированием и отменой; сохранение заявок, управление участниками, приглашения и общий чат. Просроченные встречи скрываются из поиска.
- Поиск людей рядом с фильтром по возрасту; поиск по спискам симпатий и чатам. карта встреч и людей при добровольном включении геопоиска, с выдачей только приблизительного положения.
- Блокировка пользователей, жалобы на профили и встречи, список блокировок.
- Удаление аккаунта и базовые инструменты модерации.

Некоторые функции зависят от применения соответствующих SQL-миграций и настройки Supabase. Наличие кода в репозитории само по себе не означает, что миграция уже выполнена в конкретном проекте.

## Требования

- Node.js LTS
- npm
- Проект Supabase с URL и публичным ключом приложения

## Запуск на Windows

Открой PowerShell в папке проекта:

```powershell
npm.cmd install
npx.cmd expo start --web
```

Для запуска через Expo:

```powershell
npx.cmd expo start
```

Для проверки TypeScript:

```powershell
npm.cmd run typecheck
```

## Обновление проекта

В репозитории есть скрипт `scripts/update-posidim.ps1`, который синхронизирует исходники, конфигурацию, документацию и SQL-файлы из `main`, сохраняет локальные `node_modules` и `.expo`, затем устанавливает зависимости. SQL-миграции он не запускает. Запускай его из корневой папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\update-posidim.ps1
```

Скрипт не выполняет SQL в Supabase автоматически. SQL-миграции запускаются отдельно в Supabase SQL Editor и только если они ещё не применялись.

## Структура

- `app/index.tsx` — основной интерфейс приложения.
- `lib/supabase.ts` — подключение Supabase.
- `supabase/` — SQL-схема, политики доступа, функции и миграции.
- `supabase/functions/` — Edge Functions.
- `docs/LAUNCH_CHECKLIST.md` — чек-лист перед публичным запуском.
- `docs/EAS_SETUP.md` — привязка Expo/EAS и сборки Android/iOS.
- `docs/COMMUNITY_RULES_DRAFT.md` — черновик правил сообщества.

## Важные замечания

- В клиентском приложении используется только публичный Supabase key. Никогда не добавляй `service_role` или secret key в мобильное/web-приложение.
- Не публикуй точные координаты пользователей. Геопоиск должен быть добровольным и отключаемым.
- Email подтверждается через `posidim://auth/confirm`, восстановление пароля — через `posidim://auth/callback`; в Supabase Auth Redirect URLs нужно разрешить оба адреса и соответствующие пути на web-сайте.
- Push-разрешение запрашивается только по нажатию пользователя в профиле; нажатие на push открывает соответствующий раздел приложения. Для реальной доставки на Android/iOS нужно настроить EAS projectId и push credentials; web push не подключён.
- Push-уведомления, модерация и удаление аккаунта требуют настройки и проверки соответствующих серверных функций.
- Перед публичным запуском нужно пройти чек-лист безопасности, протестировать сценарии с несколькими аккаунтами и проверить юридические документы для стран распространения.
